# Implementation plans

planは現在の実装順序、scope、acceptance criteriaを定義します。architectureの正本ではありません。

## Sequence

1. [Foundation](foundation.md)
2. [Node Management v1](node-management-v1.md)
3. Workload Runtime v1
4. Server Data v1
5. Minecraft Server Control v1
6. Minecraft Server Lifecycle v1
7. Operator automation

後続planは直前milestoneの実測と学習を反映して作成します。空の未来planを大量に作りません。

## Plan template

- Goal
- In scope
- Out of scope
- Required decisions
- Implementation slices
- Acceptance criteria
- Exit conditions
- Risks and open questions
